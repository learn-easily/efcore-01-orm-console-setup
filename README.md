# EF Core კონსოლში — ლექცია

ORM, EF Core და პროექტის მომზადება 4 ნაბიჯში (Console App, .NET 10, SQL Server). ანიმაციური HTML პრეზენტაცია + ლექტორის სცენარი.

| ფაილი | რა არის |
|---|---|
| `index.html` | პრეზენტაცია (37 სლაიდი) |
| `script.html` | ლექციის სცენარი — წასაკითხად / დასაბეჭდად |
| `deck/` | წყარო: სლაიდები და შენიშვნები (`ef.html`), ძრავი (`engine.*`), ბილდი (`build_ef.py`) |

## გამოყენება

1. გახსენი `index.html` Chrome-ში ან Edge-ში, გადაიტანე პროექტორზე, დააჭირე `F`.
2. დააჭირე `P` — გაიხსნება **ლექტორის ფანჯარა** სცენარით. დატოვე ლეპტოპის ეკრანზე.
3. `→` / `Space` — შემდეგი, `←` — წინა.

სხვა კლავიშები: `N` შენიშვნები · `O` ყველა სლაიდი · `A` სლაიდის ყველა ნაბიჯი · `Shift+→` შემდეგი სლაიდი.

## ცვლილების შეტანა

სლაიდები და სცენარი ერთ ფაილშია: `deck/ef.html` (სცენარი — `<aside class="notes">`-ში). შემდეგ:

```bash
cd deck && pip install pygments && python3 build_ef.py
cp ../out/index.html ../index.html && cp ../out/script.html ../script.html
```
